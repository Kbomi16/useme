# 둘러보기 검색·카테고리·배너 설계

날짜: 2026-09-17  
상태: 승인됨 · 바로 구현  
범위: `/discover` 상단에 숨고형 검색·카테고리·프로모 배너를 붙인다. 랜딩 `/`는 바꾸지 않는다. Auth·검색 API는 넣지 않는다.

선행 스펙 `2026-09-17-discover-home-design.md`의 오늘의 카드·최근 카드·상세 이동은 유지한다. 그 문서의 “검색·카테고리 칩 없음”만 이 스펙이 덮어쓴다.

## 1. 목표

1. `/discover` 맨 위는 질문 + 검색창 + `내 프로젝트 올려보기`다.
2. 그 아래 카테고리 한 줄이다. 맨 앞이 `전체`, 이어서 `생산성` `개발` `생활` `소셜`.
3. 그 아래 프로모 배너 한 장이다. 직사각형이다. 모서리를 크게 둥글리지 않는다.
4. 배너를 누르면 `/upload`로 간다.
5. 검색·카테고리는 예시 일곱 장만 화면에서 거른다. 서버 검색은 없다.
6. 걸리는 카드가 없으면 `이 칸에는 아직 카드가 없어요.`를 보여 준다.
7. `page.tsx`는 Server Component다. 새 애니메이션은 없다.

## 2. 화면 구조

```
AppHeader
└─ /discover
   ├─ 질문: 어떤 프로젝트를 써 볼까요?
   ├─ 검색창 + 내 프로젝트 올려보기
   ├─ 카테고리: 전체 | 생산성 | 개발 | 생활 | 소셜
   ├─ 직사각 배너 → /upload
   ├─ 오늘의 카드 (필터에 자리비움이 있을 때만)
   └─ 최근 카드 (나머지 매칭) 또는 빈 칸 문구
```

페이지 제목 `둘러보기` 큰 헤더는 쓰지 않는다. 질문은 검색 블록의 제목이다.

## 3. 카피

| 위치 | 문구 |
| --- | --- |
| 질문 | 어떤 프로젝트를 써 볼까요? |
| 검색 플레이스홀더 | 자리비움, 영수증함, 커밋모음 |
| 검색 레이블 | 프로젝트 찾기 |
| 올려보기 | 내 프로젝트 올려보기 |
| 배너 제목 | 세 칸만 채우면 카드가 돼요 |
| 배너 보조 | 이름, 한 줄, 써 볼 주소. 왜·뭘·얼마나. |
| 빈 결과 | 이 칸에는 아직 카드가 없어요. |

## 4. 카테고리 매핑

| slug | 이름 | category |
| --- | --- | --- |
| seat | 자리비움 | 생산성 |
| receipt | 영수증함 | 생활 |
| commits | 커밋모음 | 개발 |
| lunch | 점심투표 | 소셜 |
| lights | 불끄기 | 생산성 |
| meeting | 회의한장 | 생산성 |
| oncall | 당번표 | 생산성 |

`소셜`은 점심투표 한 장이다. 검색어와 카테고리를 같이 걸면 둘 다 맞아야 한다. 이름·한 줄에 검색어가 들어가면 된다.

## 5. 배너

- 한 장, 슬라이드 없음.
- `rounded-none`. `rounded-2xl` / `rounded-3xl` / `rounded-full` 금지.
- 가로로 긴 직사각형. 배경은 `primary` 연한 톤.
- 전체가 `/upload` 링크다.

## 6. 컴포넌트

| 단위 | 위치 | 경계 |
| --- | --- | --- |
| `SampleProject.category` | `sampleProjects.ts` | 데이터만 |
| `DiscoverBrowse` | `discover/_components/` | 클라이언트. 검색·카테고리 상태. |
| `DiscoverPromoBanner` | `discover/_components/` | 직사각 배너 |
| `DiscoverPage` | `discover/page.tsx` | 서버. 데이터를 Browse에 넘김 |

오늘의 카드·최근 카드 기존 컴포넌트는 재사용한다.

## 7. 검증

- `/discover`에서 질문·검색·다섯 카테고리·직사각 배너·기존 레일이 보인다.
- `개발`이면 커밋모음만. `소셜`이면 점심투표만.
- `자리` 검색이면 자리비움이 오늘의 카드로 남는다.
- 없는 검색어면 빈 칸 문구.
- 배너·올려보기 → `/upload`.
- `/` 랜딩은 그대로다.
- 새 애니메이션 없다.
